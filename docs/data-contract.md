# Game Signal public data contract

The public repository receives reviewed publication data only. Raw SQLite files, scrape artifacts, credentials, browser profiles, private notes and Agent prompts never enter this repository.

## Files

- `public/data/manifest.json`: schema version, generation time, latest issue and issue archive.
- `public/data/status.json`: latest collection, publish state, continuous live days and delay marker.
- `public/data/scoring.json`: public snapshot of the current deterministic scoring weights and discounts.
- `public/data/issues/YYYY-MM-DD.json`: one public `star_signal`, facts, scores, trends, source links and `star_appearance` count. `main_signal` remains a compatibility alias for the star during the transition; `secondary_signals` is intentionally empty.
- `public/data/weekly/manifest.json`: weekly issue archive and latest weekly pointer.
- `public/data/weekly/<slug>.json`: one weekly issue with five signals, two selected deep case slots, three watch-table signals and chart JSON references. The weekly `title` is an editorial hook, not a date range or a repeat of the selected game names; `summary` names the two selected deep cases instead of describing automation. Use `week_start` and `week_end` for coverage dates and `published_at` only for publication time.
- `public/data/charts/<appid>.json`: derived hour-level player curve, daily peaks and window peak from reviewed SteamDB chart imports.
- `public/data/games/<slug>.json`: game metadata and the published trend series. `name` keeps the Steam/source title, while `name_cn` is the preferred public display title when a Chinese name has been verified.
- `content/cases/<slug>.md`: reviewed deep case. `game_appid` identifies the subject game and the public export materializes its resolved `cover_image_url` for list, article and social-preview rendering.
- `content/companies/<slug>.md`: reviewed company profile.
- `public/images/issues/`: approved editorial cover images only.

## Access metadata

Reviewed markdown content can reserve a future commercial boundary through frontmatter:

- `access: free` means public sample content.
- `access: members` means member early access.
- `access: paid` means future subscription or one-off purchase.
- `access: embargo` means editorial or member preview before public release.
- `available_at: YYYY-MM-DD` records the planned public unlock date when relevant.

These fields are presentation metadata only. They are not security. Do not put paid full text, private databases, detailed raw metrics, user data or credentials into `content/` or `public/data/` until a real server-side entitlement layer exists.

## Case preview image

The case preview image is identity metadata, not an editorial illustration. The private publisher normally resolves it from the canonical game's Steam `cover_image_url` by `game_appid`; an editor can explicitly override the same field with a public HTTP(S) URL or root-relative public asset. Local absolute paths are rejected. The case index, case article and social metadata consume this one resolved value, while the UI supplies a branded fallback if the image is absent or fails to load.

## Guarantees

- A daily issue is exported only when it contains at least one ranked star signal.
- A weekly issue is published only after five signal charts are ready and the two deep signals have case/source cards.
- Scores are generated by deterministic rules. AI does not rank games.
- Old-game comeback can be refined by recent Steam news evidence into content-update comeback, discount comeback or generic comeback. Discount comeback receives a lower signal score and an additional final-score multiplier.
- Repeated daily-star wins carry rolling 30-day scoring debt and a 3-win ceiling, while `star_appearance.count` exposes all-time `摘星次数` to homepage readers.
- Public pages should render `name_cn` before `name`; ranking identity still uses appid/canonical aliases, not localized display names.
- Public facts include source links; private hypotheses remain private until reviewed.
- Public exports must not contain local absolute paths, API keys, Chrome profiles or draft research.
- Private editorial review notes and style feedback logs are never exported.
- SteamDB CSV/XLS/PNG source files remain private. Public chart JSON is derived display data and does not expose raw downloads.
- `schema_version` changes when the JSON contract makes a breaking change.
